# Shopify Headless Lab

A hands-on lab for headless Shopify storefront patterns, built one milestone at a time. Live: https://luminous-arithmetic-b993f6.netlify.app

**Stack:** Next.js 15.5 (Pages Router), React 19, TypeScript strict, MUI, Shopify Storefront GraphQL API (plain `fetch` + GraphQL codegen), Netlify.

**Done:** MUI with the Pages Router integration · Storefront API client and product list · product pages with ISR · smaller `__NEXT_DATA__` via a view model · Shopify webhook revalidation with HMAC verification · Netlify deploy · typed queries with codegen · server-only Storefront client.

**Next:** cart API routes (BFF) and cart UI.
